# 1. Purpose

V16 continues the chronological strict-blind research process used in V1–V15.

The goal is not to maximize historical accuracy. The goal is to learn one rule from the Study period, freeze it before seeing Hidden, and then measure whether the edge survives genuinely unseen data.

V16 was designed specifically to address V15's main failure:

- V15 Study: 36 / 54 = 66.67%
- V15 Hidden: 21 / 47 = 44.68%
- V15 lesson: impulse strength alone did not transport.
- V15 post-reveal clue: deeper reset/pullback appeared more relevant than raw impulse size.

V16 therefore tested whether the quality of the reset should be measured relative to the impulse itself rather than only in ATR units.

---

# 2. Blind Methodology

The test was run in this order:

1. Confirm the next chronological period was untouched.
2. Open only the Study period: 15–28 Nov 2025.
3. Keep 29 Nov–5 Dec completely hidden.
4. Re-test V15-derived ideas only on Study.
5. Reject the V15 post-reveal threshold `pullback >= 1.0 ATR` after it failed to transport into V16 Study.
6. Test impulse/pullback geometry using a relative retracement ratio.
7. Test nearby thresholds rather than a single magic threshold.
8. Choose one official rule.
9. Explicitly freeze the rule before accessing Hidden.
10. Open Hidden only after freeze.
11. Apply the frozen rule without any modification.
12. Preserve all misses.
13. Run post-reveal diagnostics only after official scoring.

No Hidden information was used to select the official V16 rule.

On V16 Study, the inherited deep-reset idea based on an absolute ATR threshold failed.

Representative result:

- Impulse >= 1.25 ATR
- Pullback >= 1.0 ATR
- previous V15-style 4H opposite-trend veto

## Lesson

The important variable was not simply:

> "How many ATR did price pull back?"

The same ATR pullback can mean something very different after a 1.3 ATR impulse versus after a 3 ATR impulse.

This led to testing:

# Retracement Ratio = |Pullback| / |Impulse|

# 8. OFFICIAL FROZEN V16 RULE

The following rule was frozen before Hidden was opened.

## 8.1 15m Local Impulse

At signal candle `i`:

Impulse is measured from:

**close[i-10] → close[i-4]**

This spans six completed 15m steps before the pullback window.

Direction:

- Positive impulse → candidate UP continuation.
- Negative impulse → candidate DOWN continuation.

Impulse magnitude must satisfy:

**|Impulse| >= 1.25 × ATR7**

ATR7 is calculated on 15m.

---

## 8.2 15m Pullback

Pullback is measured from:

**close[i-4] → close[i]**

The pullback must be opposite the impulse direction.

Absolute pullback size must satisfy:

**0.50 × ATR7 <= |Pullback| <= 1.50 × ATR7**

---

## 8.3 Relative Reset Requirement

Define:

**Reset Ratio = |Pullback| / |Impulse|**

Require:

# 0.55 <= Reset Ratio <= 1.20

This is the key V16 innovation.

The intent is to require a meaningful reset relative to the preceding impulse rather than relying only on an ATR threshold.

---

## 8.4 4H Opposite-Trend Veto

A strong 4H trend is defined using:

- `ER6 >= 0.30`
- EMA5 vs EMA13 direction
- EMA13 3-bar slope agreeing with that direction

If the strong 4H state is opposite the local impulse:

**NO TRADE**

A neutral 4H state or a 4H state aligned with the impulse does not block the setup.

---

## 8.5 Prediction

If all conditions pass:

**Predict the next 15m candle in the original impulse direction.**

Prediction expires after exactly one 15m candle.

No mandatory:
- 5m confirmation
- D1 filter
- cooldown
- signal-body filter
- RSI filter
- volume filter

All other situations:

**NO TRADE**

# 17. Miss Classification

## A. Shallow-relative-reset failures

Several major misses clustered near the lower edge of the official ratio:

- 0.587
- 0.577
- 0.570
- 0.600
- 0.580

These cases had a visually meaningful ATR pullback, but it was still small relative to the preceding impulse.

This suggests the reset had not fully neutralized the impulse's local imbalance.

Classification:
**structural / reset-quality error**

---

## B. 4H alignment did not guarantee continuation

Examples:

- 29 Nov 22:00 DOWN prediction while 4H DOWN → MISS
- 3 Dec 03:15 UP prediction while 4H UP → MISS
- 4 Dec 07:30 UP prediction while 4H UP → MISS

This confirms the recurring lesson from V12–V15:

# Higher-timeframe alignment is context, not a confidence multiplier.

A mature 4H trend can coexist with local exhaustion, rotation, or counter-move.

Classification:
**regime / timing error**

Keep these lessons for future versions:

1. Use relative structure, not isolated indicator thresholds.
2. Stronger impulse is not automatically stronger continuation.
3. A reset that is too shallow relative to the impulse is suspicious.
