The V17 question was therefore:

> Can we improve continuation quality by requiring not only acceptable reset geometry, but also a clean and directional pullback path?

# 8. OFFICIAL FROZEN V17 RULE

The following rule was explicitly frozen before any Hidden candle was accessed.

## 8.1 Local Impulse

On 15m:

Impulse is measured from:

`close[i-10] → close[i-4]`

This represents six 15m intervals.

Direction:
- positive = UP impulse
- negative = DOWN impulse

Require:

**|Impulse| >= 1.00 × ATR7**

---

## 8.2 Pullback

Pullback is measured from:

`close[i-4] → close[i]`

Require:

- pullback direction opposite the impulse
- `0.50 × ATR7 <= |Pullback| <= 1.50 × ATR7`

---

## 8.3 Relative Reset Geometry

Define:

`Reset Ratio = |Pullback| / |Impulse|`

Require:

**0.55 <= Reset Ratio <= 1.20**

---

## 8.4 Pullback Cleanliness

Calculate:

`ER(4)` on the 15m pullback window.

Require:

# Pullback ER4 >= 0.60

This means the reset must be relatively directional rather than random alternating chop.

This is the core V17 improvement.

# 21. Main V17 Scientific Lesson

V16 taught:

> Measure reset relative to the impulse.

V17 adds:

> Measure whether the reset is clean, but also whether it has erased too much of the original impulse.

This creates a more complete concept:

# Impulse Quality → Relative Reset → Reset Cleanliness → Remaining Structural Advantage

A clean reset is not automatically bullish/bearish continuation.

If the reset fully cancels the impulse, continuation logic may no longer apply.
