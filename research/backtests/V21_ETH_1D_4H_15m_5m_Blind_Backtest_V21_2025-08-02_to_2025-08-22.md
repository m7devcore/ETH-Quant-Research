# 1. Objective

V21 was designed after reviewing the full V1–V20 research corpus.

The explicit objective was not to maximize Study accuracy. The goal was to find a rule or model that survives repeated verification inside Study before opening Hidden.

A new verification discipline was added:

1. First calculation
2. Independent verification
3. Recalculate if uncertain or inconsistent
4. Freeze only after repeated confirmation

This was added on top of the existing blind protocol:

Study → freeze exact rule → open Hidden → apply unchanged → preserve official score → post-reveal diagnosis only afterward.

---

# 2. What V1–V20 Taught Before V21

The 20 prior reports were treated as one reference base.

Permanent lessons carried forward:

- Regime before direction.
- Invalidated bias must be abandoned.
- NO TRADE is a legitimate model output.
- Rejection appearance is not the same as failed acceptance.
- Low ER is not automatically a range.
- Large displacement can be repricing rather than exhaustion.
- Local failed breakout requires structural permission.
- Correct higher-timeframe direction does not guarantee next-candle timing.
- Repeated boundary occupation changes signal meaning.
- Stronger impulse does not automatically imply better continuation.
- Relative reset geometry is more meaningful than fixed pullback depth alone.
- Clean pullback is not sufficient.
- Mature aligned trend can create bad timing.
- Setup quality is not calibrated probability.
- Volatility magnitude alone is not regime permission.
- 4H Neutral is too broad a state.
- Value migration can matter, but V20 showed that a single migration threshold is not enough.
- Historical windows already seen are research data, not fresh validation.
- A rule should not be considered learned until it survives data unseen at the time of freezing.

# 18. Model Formula

Each feature was standardized using Study-only statistics:

`z_j = (x_j - mean_j) / sd_j`

Logit:

`L = b0 + Σ(w_j × z_j)`

Probability:

`p = 1 / (1 + exp(-L))`

Final decision:

- `p >= 0.58` → UP
- `p <= 0.42` → DOWN
- otherwise → NO TRADE

Regularization:

# L2 = 0.20

Training settings:

- 350 gradient steps
- learning rate 0.04

# 41. Main Scientific Lesson

V20 taught:

> Volatility is not regime permission.

V21 adds:

# Internal walk-forward validation inside one regime is still not enough.

A model can pass multiple chronological folds, baseline comparison, coefficient freeze and confidence filtering, and still fail when the macro data-generating process changes.

The missing concept is:

# regime-invariant learning

or explicitly:

# regime-conditioned experts trained across multiple distinct historical environments.

# 43. Proposed V22 Architecture

Maximum three candidate families.

## Family A — Static multi-regime model

Train one model across many already-seen research regimes rather than one 14-day block.

Use period-balanced and direction-balanced sampling so one bull or bear period cannot dominate.

## Family B — Regime-conditioned experts

First classify state:

- trending up
- trending down
- neutral/rotation
- volatility expansion/repricing

Then use a separate directional model for each state.

## Family C — State-change veto

If the current state is too far from the support of the relevant training regime:

# NO TRADE

The veto must be state-specific. A generic Euclidean/OOD norm was not enough.
