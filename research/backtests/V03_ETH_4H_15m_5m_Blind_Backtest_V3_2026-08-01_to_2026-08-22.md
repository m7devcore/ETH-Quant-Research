# 1. Objective

This report extends the ETH training sequence after the first two blind reports.

The objective is not to fit a perfect historical system. It is to test whether the lessons learned from V1 and V2 improve the analysis when a completely earlier, unseen market regime is revealed.

The three key inherited principles were:

1. A forecast must be conditional rather than defended after invalidation.
2. A large wick is not the same thing as breakout acceptance.
3. Market regime must be identified before selecting the directional rule.

V3 also adds a new timeframe:

- 4H = structural / regime timeframe
- 15m = setup timeframe
- 5m = micro-confirmation timeframe

---

# 2. Lessons Imported From V1 and V2

## From V1
The first report showed that:
- lagging bearish structure was overweighted,
- a major resistance zone was treated too rigidly,
- breakout extension was underestimated,
- the old forecast was kept alive too long.

The permanent process became:

**Trigger → Confirmation → Invalidation → Flip → Reassessment**

## From V2
The second report showed that:
- a small in-sample edge can disappear out of sample,
- 4H momentum can mean continuation in one regime and exhaustion in another,
- high indicator magnitude is not automatically high confidence,
- 15m candle-by-candle prediction can be almost random,
- NO TRADE is a valid output,
- the key missing component was **regime detection before direction prediction**.

V3 therefore does not force a trade on every candle.

# 13. The Main 4H Error

The regime-flip logic worked.

The **regime-exit logic did not**.

Once the model entered bullish acceptance above $1,943, it effectively remained bullish indefinitely.

That was too simplistic.

By 21–22 August, ETH had already expanded from roughly $1,900 to above $2,500.

The 22 Aug 07:00 candle then dropped about:

**-3.25%**

After that major bearish structural shock, the model should have stopped using the original breakout-continuation state and re-run the structure.

Instead, it kept predicting UP and produced multiple additional misses.

### Diagnostic only
If V3 had frozen bullish continuation after the large 22 Aug bearish break and required reassessment:

- Signals retained: 15
- Correct: 10
- Accuracy: **66.67%**
- Four later stale signals would have been avoided.

This diagnostic was calculated after reveal, so it is **not part of the official V3 score**.

It becomes a lesson for V4.

# 26. V4 Rule Changes Learned From V3

The next training version should add:

## 1. Breakout-state expiry
A regime flip must not remain active forever.

After a major adverse 4H structural candle:
- pause continuation signals,
- reclassify the regime,
- rebuild support/resistance.

## 2. Lower-timeframe state reset
When 4H changes regime, 15m and 5m should not keep using rules calibrated in the old regime.

Their local range statistics should be rebuilt after the regime change.

## 3. 5m demotion
5m should become:
- execution timing,
- rejection confirmation,
- entry refinement,

not the main directional source.

## 4. 15m Grade A only until more evidence exists
The 15m failed-breakout fade is the only lower-timeframe V3 rule that showed similar study and hidden accuracy.

It deserves further testing, not blind trust.

## 5. Add trade-quality metrics
Future reports should include:
- MAE
- MFE
- ATR-adjusted stop
- target distance
- fee/slippage model
- expectancy per signal

# 30. User-Level Summary

The hidden week was one of the best possible stress tests for the new methodology.

The visible 1–14 Aug period looked like a range.

The hidden 15–22 Aug period suddenly produced a **+29.34%** ETH expansion.

V3 did not predict the exact explosion in advance.

That is not its main success.

Its main success was:

1. staying cautious while the range was intact,
2. identifying $1,943 as the important structural ceiling,
3. waiting for actual 4H acceptance,
4. flipping bullish instead of repeatedly shorting the breakout,
5. capturing most of 19–21 Aug correctly.

The biggest remaining errors were:

- keeping the bullish 4H state alive too long on 22 Aug,
- assuming 15m range mean reversion would survive a regime change,
- overestimating the reliability of the 5m failed-breakout rule.

The strongest new lesson is:

# A regime-change rule also needs a regime-expiry rule.

The next version should not only know **when to flip**.

It must also know **when the new trend thesis has become stale and must be rebuilt**.
